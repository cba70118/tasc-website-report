Section 1

For developers

Changes to the Shopify theme. Each one lists the files to look for, the code, and how to check it worked.

D1

Add Google's "preferred source" button to blog posts

Time: about 1 hour with testingWhere: blog post template, theme headAffects: 295 blog posts

Google lets readers pick the sites they want to see more of. When someone adds tasc as a preferred source, tasc's articles are more likely to appear for them in Google's Top Stories, marked with a "preferred" badge, and in AI Overviews and AI Mode. Since August 2026 Google offers a ready-made button so readers can do this in one tap without leaving the page.

Check first: the button only works for sites Google lists in its source preferences tool, which happens for sites that have appeared in Top Stories. Search for tascperformance.com at google.com/preferences/source. If it appears, go ahead. If not, park this until it does.

  1. Load Google's script on blog posts only. The script is about 40 KB to download, and pages are already heavy, so don't load it sitewide. In theme.liquid, inside <head>: 
    {%- if template.name == 'article' -%}
  <script async src="https://news.google.com/swg/js/v1/publisher.js"></script>
{%- endif -%}
  2. Place the button at the end of each post. In the article template, just above the existing Article-buttonWrapper ("Back to tasc Life"): 
    <div google-add-preferred-source-btn data-lang="en"></div>
    Add data-theme="dark" only if it sits on a dark background.
  3. Check it: open any blog post on a phone and a desktop. The Google-styled "Add to preferred sources" button should appear above "Back to tasc Life", and it shouldn't appear on product or collection pages.

Source: Google Search Central, Preferred Sources guide.

D2

Make the theme output image descriptions

Time: about 1–1.5 hoursWhere: two shared image snippets, mega menu, size guide, hero videoAffects: every page

Across all 995 pages, 16,073 of 29,923 images (54%) have no written description in the page source. They come from 145 unique images, and almost all of them pass through two shared theme snippets that never print a description at all. Fixing those snippets lets the content team add descriptions in the Shopify admin (C3) without touching code.

Worth knowing: the AudioEye accessibility tool patches most of these after the page loads. Mostly it marks them as decorative, and for a few it guesses a label (it labels the footer logo "TASC Logo"). That's why Google's Lighthouse accessibility check passes even though the descriptions are missing. With AudioEye blocked, 18 of the 42 images on a product page have no description. Fixing the theme removes the dependence on that patch.

WhereImagesFix
Snippet that renders lazypicture (collection banners, hero banners, FAQ images, footer logo)77Print the file's description
Snippet that renders responsive-image-wrapper (feature blocks, page banners, infographics, icons)41Print the file's description
Hero video posters8Print the video's description
Size guide pop-up (fit images)7Hard-code descriptions
Mega-menu tiles using a custom image5Mark decorative

  1. The two shared snippets. Find the snippets that output the lazypicture and responsive-image-wrapper markup. In each, add the image's own description to the <img> tag (use whatever the snippet calls its image variable): 
    alt="{{ image.alt | escape }}"
    Shopify fills image.alt from the description saved on the file under Content → Files. Until content fills one in it prints alt="", which is still valid.
  2. Hero video posters. Where the hero section renders the video's preview image, add alt="{{ video.alt | escape }}".
  3. Mega menu. The five tiles that use a custom uploaded image sit right beside their link text, so a description would just repeat it. Mark them decorative: add alt="" in the custom-image branch of the menu snippet.
  4. Size guide. These images are fixed in the theme, so hard-code the descriptions from the image list (rows 7–13), e.g. alt="Men's semi-fit shown on a model in a navy quarter-zip".
  5. Check it: view the page source of any product page (Ctrl+U in Chrome shows it before AudioEye runs), search for <img, and confirm every tag has alt=.
D3

Stop product descriptions being cut off in search results

Time: about 15 minWhere: theme.liquid and the social meta snippetAffects: products without their own SEO description

When a product has no SEO description, Shopify fills one in from the first 320 characters of the product description. Search results show about 155, so many listings end mid-word. For example, the NOLA Long Sleeve's ends with "…Explore ou". 11 of 20 products checked are affected.

  1. Find the description tag in the theme head: 
    <meta name='description' content='{{ page_description | escape }}'>
  2. Replace it with: 
    <meta name='description' content='{{ page_description | strip_html | strip_newlines | truncate: 155 | escape }}'>
  3. Make the same change to the og:description tag in the social meta snippet. It carries the same 320-character text.
  4. Check it: view the source of the NOLA Long Sleeve page. The description should be 155 characters or fewer and end in "…".

Worth knowing: this is a tidy safety net, but it can still cut mid-sentence. The better long-term fix is a written description per product, which content can do in bulk through the product CSV export (the "SEO Description" column).

D4

Give the header logo a size, so the page stops jumping

Time: about 10 minWhere: header snippetAffects: every page

The homepage fails one of Google's real-shopper speed checks: it jumps around while loading (0.29 against a limit of 0.10, in Google's September data). Lighthouse traced the biggest jump, on both the homepage and product pages, to the header logo. The theme prints it with empty size fields, width="" height="", so the browser can't save room for it. When the logo arrives, the header grows and pushes the whole page down.

  1. Find the logo in the header snippet. It currently outputs: 
    <img src="//www.tascperformance.com/cdn/shop/files/Mobile-8_1.png" alt="tasc Performance" width="" height="">
  2. Replace it with Shopify's image_tag, which prints the real width and height. Use the header's actual logo setting name: 
    {{ section.settings.logo
   | image_url: width: 300
   | image_tag: alt: shop.name, class: 'header-logo-image' }}
    Or, if the logo is hard-coded, fill in the numbers: width="150" height="48". That's the size it displays at on phones, and CSS can still scale it.
  3. Check it: run the homepage through PageSpeed Insights. The "Avoid large layout shifts" item should no longer point at header-logo. Google's real-shopper figure updates over the following 28 days.
Section 2

For content and writers

Changes made in the Shopify admin. No code needed.

C1

Rewrite the homepage title and description

Time: about 15 minWhere: Online Store → Preferences → Title and meta description

The homepage title is 82 characters. Search results show about 60, so "tasc Performance" is cut off the end of tasc's own listing. The description is fine on length but doesn't mention bamboo, which is what sets tasc apart.

Title

The theme adds " – tasc Performance" automatically, so leave the brand out and keep the field to 41 characters or fewer.

Bamboo Activewear & Athletic ClothingRecommended. Shows as "Bamboo Activewear & Athletic Clothing – tasc Performance" (56 characters). Keeps the current keywords and matches the collection titles.
Activewear & Athletic ClothingAlternative. Shows as 49 characters.

Description

We make better t-shirts, pants, golf polos and yoga clothes from soft, bamboo-based fabric, so you can move better, feel better and live better.Recommended (144 characters). Keeps the current voice, and nothing in it goes out of date.
Shop t-shirts, polos, pants and yoga clothes made with soft, bamboo-based fabric that wicks moisture and resists odor. Free shipping over $150.Alternative (143 characters). Only use this if someone will update it when the shipping amount changes.

Google usually updates the listing within a few days to two weeks. Search Console → URL Inspection → Request indexing can speed it up.

C2

Update the free-shipping amount in collection descriptions

Time: about 10 minWhere: Products → Collections → each collection → Search engine listing

The site banner says "Free Shipping on Orders $150 or More!", but 5 of the 72 collection descriptions shown in search results still say "Free shipping over $100." Shoppers who click expecting $100 find a different offer.

  1. Open these five collections and edit the Search engine listing description: Women's Yoga, Women's Short Sleeve, Women's Sports Bras, Women's Running and Men's Joggers.
  2. Change "$100" to "$150", or remove the shipping line so it can't go stale again.
C3

Write descriptions for 131 images

Time: about 3 hoursWhere: Content → Files, and product media for 4 videosNeeds first: D2

Start with the plain-language guide (CSV), which explains what alt text is, why it matters and how to enter it in Shopify. The image list (CSV) has every image on the site that's missing a description: 150 in total, found by scanning all 995 pages and cross-checking against Screaming Frog and Sitebulb crawls. Each row has a suggested description written after looking at the picture and reading the copy around it. Where it reads naturally, the description also carries the page's own keyword and the tasc brand or product name (for example, "Woman by the ocean in a white tasc bamboo T-shirt from our women's tops"). Each row also shows the target keyword, the plainer earlier version, how many pages the image appears on, and where to enter the text. Many banners come in desktop and mobile pairs, so the 131 images that need text need only 92 different descriptions. The other 19 should be marked decorative, left as they are, or handed to a developer or app vendor.

  1. For most images: Content → Files, search the file name from the list, open it and paste the description into Alt text. It shows on the site once D2 is live.
  2. For the four product videos (rows 47, 67, 73, 74): open the product, click the video in Media, and choose Add alt text.
  3. Graphics with words in them ("It's all in the details", the Motion Short feature graphic, the review-count banners, the fit comparisons) need a description that repeats the words, because a screen reader can't read text inside an image.
  4. Add "ID.me" to the ID.me logo on the Community Discounts page (row 146). It currently has an empty description, so screen readers skip the one sign that discounts are verified through ID.me.
  5. Keep it natural. Describe what is in the picture first, and only add a keyword or brand name where it fits the sentence. Each description is under 125 characters, and fabric claims match the page copy (the Cloud Polo is beechwood, Sculptive is REPREVE recycled fabric, and the Motion Short is bamboo and cotton). The athletes are named on the Ambassadors page: Alex Smalley, Trey Winstead, Sam Saunders and Wil Lutz.
  6. Delete one empty image in the blog post "Essential features to look for in men's running outfits" (row 26). It has no picture in it.
